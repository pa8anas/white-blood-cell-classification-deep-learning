# Notebooks

Use this directory for Kaggle/Jupyter experiment notebooks.

Suggested naming convention:

```text
01_data_exploration.ipynb
02_custom_cnn.ipynb
03_vgg16.ipynb
04_resnet18.ipynb
05_model_comparison.ipynb
```

For reproducibility, keep the reusable training/data/model code in `src/` and use notebooks mainly for experiments, visualizations, and result discussion.

Do not upload the Blood Cell Images dataset to this repository.
